# Algorithmic Reasoning & Numerical Verification Suite

A Python verification suite of mathematical and numerical algorithms developed from first principles to evaluate step-by-step reasoning proofs and iterative matrix convergence in STEM domains.

## Key Features
- **First-Principles TDMA Solver:** Implementation of the Tridiagonal Matrix Algorithm (Thomas algorithm) for coupled linear algebraic systems.
- **ASME Grid Convergence Index (GCI):** Numerical spatial discretization error verification evaluating apparent order of convergence ($p$) and fine-grid asymptotic bounds.
- **Analytical Benchmark Validation:** Rigorous error tracking comparing discrete numerical profiles against exact closed-form solutions.
